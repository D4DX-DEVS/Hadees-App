5. Data-entry team: how to check a book

  1. Open the book in the app. Count the hadith (the count must match section 2).
  2. For each flagged hadith in section 3, open the scanned page (the printed page number is shown on the page footer).
  3. Check the first and last hadith of each chapter against the scan.
  4. Check the Arabic text and its harakat against the print. Do not add vowels that are not printed.
  5. Note any difference in a shared sheet with: vol, book, hadith number, scanned page, what the print says, what the app shows.
