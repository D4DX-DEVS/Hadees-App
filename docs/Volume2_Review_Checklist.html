Volume 2 is fully entered. What is left is a short list of places where the scan is damaged or a checker could not decide a spelling. Everything below can be settled with the printed book in hand.

Action plan

  1. Part A (priority 1) — photograph. For each of the 5 tickets, find the printed page, take the photo as described below, and write the hidden word if the book shows it clearly.
  2. Part B (priority 2) — confirm. For each of the 7 tickets, look at the book and write what is printed. Tick the status box.
  3. Part C (priority 3, optional) — spelling. Only if time allows. These are cases where the print itself is inconsistent.
  4. Send back the photos plus this sheet (a photo of the ticked pages, or the answers typed in a message) in the Volume 2 chat.
  5. Update. Each answer is applied to the page file, the book is rebuilt and reloaded into the database, the hadith cross-links are recomputed, and the «needs review» flag is cleared on every ticket that was confirmed.
How to take the photo
  • Flat page, daylight or an even lamp, no shadow across the line, no fingers on the page.
  • Phone at highest quality. Take two: the whole page, then a close-up of the marked line.
  • Name the files v2-<part>-p<pdfpage>.jpg, e.g. v2-2.3-p57.jpg, so each photo matches its ticket.
  • Printed page = the number printed in the book. PDF page = the page number inside the PDF file (shown for reference only).
